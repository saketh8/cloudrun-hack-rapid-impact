# Scenario Brief – Rapid Impact Partner Assistant

## Context

- Stakeholder: Small nonprofit “Gulf Coast Food Collaborative”
- Event: Weekend mobile pantry outreach serving three neighborhoods
- Pain Point: Staff need to quickly communicate outcomes to donors, update social media, and inform volunteers of next steps.

## Goals

1. Generate donor newsletter content summarizing outcomes and gratitude.
2. Produce a social-ready caption with metrics and call-to-action.
3. Create an internal checklist covering follow-up tasks (thank-you calls, inventory restock, next event planning).

## User Flow

1. Staff member opens the web app and enters key details (date, volunteers, meals served, notable stories).
2. Hits “Generate”; backend calls Gemini with structured prompts for each output.
3. UI displays three sections with copy the user can copy/download/edit.
4. Optional: Save results to Firestore and email/share using future integrations.

## Success Metrics

- Time to produce communications drops from hours to minutes.
- Generated content matches nonprofit tone and includes quantitative results.
- Staff report clarity on follow-up steps post-event.
